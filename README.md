
# PLP Python Week 4 Assignment

This assignment focuses on Python functions, parameters, return values, and default arguments.

## Files

- welcome.py: Contains a welcome() function that returns greeting messages for different people.
- toolbox.py: Contains three functions: double(), is_pass(), and greet(), with test examples.

## Reflection

The hardest function to write was greet() because it uses a default parameter. I had to understand how Python uses "Hello" automatically when no greeting is provided.
